# Motos Prime

Protótipo de site para apresentação de seguros e planos para motociclistas.

![Status](https://img.shields.io/badge/status-Prot%C3%B3tipo%20%E2%80%94%20n%C3%A3o%20finalizado-blue?style=flat-square)

**Tecnologias:** HTML · CSS · JavaScript

## Sobre

A proposta é reunir informações sobre planos, dúvidas frequentes, contato e contratação em uma experiência simples. Atualmente existe a interface estática; contratação, cobrança e envio de mensagens ainda não estão implementados.

## O que já existe

- Páginas de apresentação, planos, FAQ, contato e recrutamento.
- Menu para dispositivos móveis e FAQ expansível.
- Resumo de plano escolhido na página de demonstração.

## Como visualizar

Clone o repositório e abra `index.html` no navegador. Para testar por HTTP, use a extensão Live Server do seu editor. Preserve as pastas de CSS, JavaScript e imagens. Não há dependências locais para instalar; recursos de CDN exigem internet.

## Observações

Este projeto é demonstrativo. Não contrata seguros, não processa pagamentos e não envia o formulário de contato. Não informe dados pessoais reais.
